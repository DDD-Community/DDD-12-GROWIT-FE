# Task 01. 주간 투두 레이아웃 개선

> 프론트엔드 변경 계획: [주간 레이아웃 프론트엔드 문서](../frontend/01-weekly-layout.md)

## 목적

주간 매트릭스에서 네 카테고리 카드가 콘텐츠 개수와 무관하게 지정된 높이를 유지하도록 한다.
투두가 많을 때 카드 전체가 늘어나거나 잘리지 않게 하고, 카드 헤더는 고정한 채 목록만 스크롤되도록 한다.
하단 내비게이션이 메인 콘텐츠 영역을 가리는 문제도 함께 해결한다.

## 현재 구조

- `TodoListContainer`가 주간 뷰에서 `TodoList`의 `matrix` 모드를 사용한다.
- `MatrixView`는 `중요`와 `여유` 두 행에 각각 카테고리 카드 두 개를 배치한다.
- `CategoryCard` 전체에 `overflow-hidden`이 적용되어 있지만 목록 전용 스크롤 영역은 없다.
- 카드와 행 높이가 `flex-1`에 의존하여 화면 높이와 콘텐츠 양에 따라 달라질 수 있다.
- `BottomNavigation`은 `fixed bottom-0`이며 콘텐츠 스크롤 컨테이너 내부에 렌더링된다.

## 구현 범위

### 1. 카테고리 공통 높이

| 분류 | 카테고리 | 카드 높이 |
| --- | --- | ---: |
| 중요 | `NOW` 긴급 | `295px` |
| 중요 | `STEADY` 꾸준히 | `295px` |
| 여유 | `SKIP` 넘겨도 | `180px` |
| 여유 | `DELETE` 지워도 | `180px` |

- 높이는 카테고리별 콘텐츠 개수와 무관하게 유지한다.
- 같은 행의 두 카드는 동일한 높이를 사용한다.
- 작은 화면에서도 카드 폭은 현재의 2열 구조를 유지한다.
- 전체 화면의 세로 스크롤은 허용하되 카드 높이를 축소하지 않는다.

### 2. 카드 내부 스크롤

`CategoryCard`를 헤더와 목록 영역으로 분리한다.

```text
CategoryCard (고정 높이, overflow hidden)
├── Header (shrink-0)
│   ├── 카테고리 아이콘
│   ├── 카테고리명
│   ├── 완료/전체 개수
│   └── 추가 버튼
└── Todo list (min-h-0, overflow-y-auto)
    └── TodoItem...
```

- `긴급 0/1`과 추가 버튼이 포함된 헤더는 스크롤되지 않는다.
- 투두 목록만 `overflow-y-auto`를 사용한다.
- 카드 클릭으로 상세 화면을 여는 동작과 내부 투두 스와이프가 충돌하지 않아야 한다.
- 스크롤바 노출 여부는 기존 모바일 UI와 일관되게 처리한다.
- 목록의 마지막 항목이 카드 패딩에 가려지지 않아야 한다.

### 3. 공통 정렬 정책 적용

주간 매트릭스의 각 카테고리 배열에 공통 정렬 함수를 적용한다.

```text
미완료 + 시간 있음       → 시간 오름차순
미완료 + 시간 없음       → 가나다순
완료 + 시간 있음         → 시간 오름차순
완료 + 시간 없음         → 가나다순
```

- 완료 여부가 시간 유무보다 높은 우선순위를 가진다.
- `time`이 `null`, `undefined`, 빈 문자열인 경우 시간이 없는 투두로 처리한다.
- 정렬 과정에서 React Query 캐시 또는 props 배열을 직접 변경하지 않는다.

### 4. 하단 내비게이션 안전 영역

- 고정된 `BottomNavigation` 높이와 `env(safe-area-inset-bottom)`을 고려한 하단 여백을 메인 스크롤 영역에 제공한다.
- 마지막 콘텐츠가 내비게이션 뒤로 들어가지 않아야 한다.
- 스크롤이 끝났을 때 마지막 투두를 읽고 조작할 수 있어야 한다.
- 플로팅 추가 버튼과 하단 내비게이션의 클릭 영역이 겹치지 않아야 한다.
- 상세 화면과 Bottom Sheet의 기존 z-index 동작을 유지한다.

## 테스트 시나리오

1. 각 카테고리에 투두가 없는 상태
2. 한 카드에 높이를 넘는 수의 투두가 있는 상태
3. 시간 있는·없는 투두와 완료·미완료 투두가 섞인 상태
4. 같은 시간을 가진 투두가 여러 개인 상태
5. 긴 제목과 한글·영문·숫자 제목이 섞인 상태
6. 카드 내부 스크롤 중 투두 스와이프 및 카드 상세 진입
7. iOS Safe Area가 있는 기기와 일반 모바일 브라우저
8. 페이지 최하단에서 내비게이션과 마지막 콘텐츠 간 간격 확인

- [ ] 여유 카드 두 개가 각각 `180px` 높이를 유지한다.
- [ ] 헤더는 고정되고 목록만 스크롤된다.
- [ ] 각 카테고리에 공통 정렬 정책이 적용된다.
- [ ] 빈 목록 안내가 카드 내부에서 정상 노출된다.
- [ ] 하단 내비게이션이 콘텐츠와 조작 영역을 가리지 않는다.
- [ ] 추가·수정·완료·삭제·상세 진입 동작에 회귀가 없다.
