# Task 03. 카테고리 상세 레이아웃 및 내비게이션 개선

> 프론트엔드 변경 계획: [카테고리 상세 프론트엔드 문서](../frontend/03-category-detail-navigation.md)

## 목적

카테고리 상세 화면의 현재 위치를 네 카테고리 전체 맥락에서 이해할 수 있도록 표시한다.
사용자가 상세 화면을 닫고 매트릭스로 돌아가지 않아도 탭 또는 좌우 스와이프로 다른 카테고리를 탐색할 수 있게 한다.

## 현재 구조

- 매트릭스 카드를 클릭하면 `TodoList`의 `detailCategory` 상태가 설정된다.
- `CategoryDetailView`는 선택된 카테고리 하나를 전체 화면 오버레이로 표시한다.
- 헤더 중앙의 `CategoryMatrixIcon`은 네 카테고리를 `2×2` 사분면으로 표현한다.
- 상세 화면 안에서 다른 카테고리로 바로 이동할 수 있는 동작은 없다.
- 상세 목록은 전달된 배열 순서를 그대로 사용한다.

## 구현 범위

### 1. `1×4` 카테고리 표시

기존 `2×2` 사분면을 다음 순서의 가로 `1×4` 표시로 변경한다.

```text
NOW | STEADY | SKIP | DELETE
긴급 | 꾸준히 | 넘겨도 | 지워도
```

- 활성 카테고리만 고유 색상을 사용한다.
- 비활성 카테고리는 기존 비활성 색상 `#404040`을 사용한다.
- 표시 순서는 매트릭스 카드 순서 및 스와이프 순서와 같아야 한다.
- 상세 헤더의 각 칸은 클릭 가능한 탭으로 제공한다.
- 탭에는 접근 가능한 이름과 현재 선택 상태를 제공한다.

`CategoryMatrixIcon`이 다른 화면에서도 사용되므로 전역 형태 변경이 의도치 않은 UI 회귀를 만들지 않도록 한다.
필요하면 상세용 variant 또는 별도 `CategoryNavigation` 컴포넌트로 분리한다.

### 2. 탭으로 카테고리 이동

- 비활성 카테고리 탭을 누르면 오버레이를 닫지 않고 해당 상세 화면으로 전환한다.
- 선택 카테고리에 맞춰 제목, 배지, 설명, 배경, 아이콘 및 투두 목록이 함께 변경된다.
- 빈 카테고리도 이동 가능하며 빈 상태 문구를 표시한다.
- 카테고리 변경 중 기존 추가·수정·완료·삭제 기능을 유지한다.

### 3. 좌우 스와이프로 카테고리 이동

순서는 다음과 같다.

```text
NOW ↔ STEADY ↔ SKIP ↔ DELETE
```

- 왼쪽 스와이프는 다음 카테고리, 오른쪽 스와이프는 이전 카테고리로 이동한다.
- 첫 카테고리에서 오른쪽, 마지막 카테고리에서 왼쪽으로 스와이프할 때는 경계를 유지한다.
- 스와이프 임계값을 둬 일반적인 탭이나 작은 움직임으로 전환되지 않게 한다.
- 세로 목록 스크롤 및 투두 항목의 가로 SwipeableRow 동작과 충돌하지 않아야 한다.
- 제스처 충돌을 줄이기 위해 상세 헤더 또는 별도 내비게이션 영역을 스와이프 감지 영역으로 우선 검토한다.

### 4. 상세 목록 정렬

상세 화면에서도 공통 정책을 적용한다.

1. 미완료 우선
2. 같은 완료 상태에서 시간이 있는 항목 우선
3. 시간이 있으면 시간 오름차순
4. 시간이 없으면 콘텐츠 가나다순

완료 토글이나 수정 후에는 갱신된 배열을 기준으로 재정렬한다.

## 상태 및 인터페이스 변경

`CategoryDetailView`가 카테고리 변경을 부모에 전달할 수 있도록 콜백을 추가하는 방식을 우선한다.

```ts
interface CategoryDetailViewProps {
  category: CategoryType;
  onCategoryChange: (category: CategoryType) => void;
  // 기존 props 유지
}
```

카테고리 순서와 메타데이터는 여러 컴포넌트에서 중복 선언하지 않도록 공통 상수로 관리한다.

## 예상 변경 파일

- `src/feature/todo/todoList/components/CategoryDetailView.tsx`
- `src/feature/todo/todoList/components/CategoryMatrixIcon.tsx`
- 필요 시 신규 `CategoryNavigation.tsx`
- 필요 시 카테고리 순서·메타데이터 공통 파일

## 테스트 시나리오

1. 네 카테고리 탭을 순서대로 선택
2. `NOW`에서 `DELETE`까지 연속 왼쪽 스와이프
3. `DELETE`에서 `NOW`까지 연속 오른쪽 스와이프
4. 양 끝 카테고리에서 경계 방향 스와이프
5. 빈 카테고리로 이동
6. 긴 투두 목록을 세로 스크롤하면서 오동작 여부 확인
7. 투두 항목 완료·삭제 스와이프와 카테고리 스와이프 충돌 확인
8. 카테고리 이동 후 투두 추가 시 선택 카테고리가 기본값으로 전달되는지 확인
9. 상세 화면 닫기 및 다시 열기

## 완료 조건

- [ ] 상세 화면에 `NOW → STEADY → SKIP → DELETE` 순서의 `1×4` 표시가 보인다.
- [ ] 활성 카테고리와 비활성 카테고리가 시각적·접근성 상태로 구분된다.
- [ ] 탭으로 원하는 카테고리 상세 화면을 바로 열 수 있다.
- [ ] 좌우 스와이프로 인접 카테고리를 이동할 수 있다.
- [ ] 첫 번째와 마지막 카테고리에서 경계가 유지된다.
- [ ] 세로 스크롤과 투두 SwipeableRow 동작에 회귀가 없다.
- [ ] 상세 목록에 공통 정렬 정책이 적용된다.
- [ ] 선택 카테고리 기준의 추가·수정·완료·삭제가 정상 동작한다.
